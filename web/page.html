Сравнение относится к указанной ветке и компоненту. Совпадение версии не подтверждает наличие всех security fixes или совместимость всего окружения.

Как пользоваться и обновлять таблицу
  1. Откройте этот HTML-файл обычным браузером Windows.
  2. На CM-сервере создайте файл командой python3 ibm_discovery.py --json > inventory.json и перенесите его на Windows доступным в вашей сети способом.
  3. Нажмите «Открыть inventory.json». Сравнение происходит в браузере; файл никуда не отправляется.
  4. Ссылки открывают IBM Support или Fix Central. Там выбирают платформу, входят с IBMid и скачивают пакет. Скачивание с учётной записью IBM здесь не проверяется.

Каталог встроен в страницу и сам не обновляется при её открытии. Возьмите свежий HTML из репозитория или откройте новый catalog.json. Сборка страницы в существующем GitHub Actions выполняется после обновления каталога.

Некоторые существующие сборщики проверяют фиксированную страницу уже известного релиза. Дата получения такой страницы не доказывает отсутствие более новых исправлений. Дополнительные примечания в этой версии проверены 06.09.2026 и имеют собственную дату.
