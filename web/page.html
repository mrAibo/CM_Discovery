Der Vergleich gilt für die angegebene Versionslinie und Komponente. Eine übereinstimmende Version bestätigt weder die Abdeckung aller Sicherheitskorrekturen noch die Kompatibilität der gesamten Umgebung.

Bedienung und Aktualisierung
  1. Öffnen Sie diese HTML-Datei in einem normalen Windows-Browser.
  2. Erzeugen Sie auf dem CM-Server im Verzeichnis des Collectors die Datei mit python3 ibm_discovery.py --json > inventory.json und übertragen Sie sie über einen vorhandenen Dateitransferweg nach Windows.
  3. Klicken Sie auf „inventory.json öffnen“. Der Vergleich erfolgt im Browser; die Datei wird nicht hochgeladen.
  4. Die Links öffnen IBM Support oder Fix Central. Dort wählen Sie die Plattform aus, melden sich bei Bedarf mit Ihrer IBMid an und laden das Paket herunter. Downloads mit IBM-Anmeldung wurden hier nicht geprüft.

Der Katalog ist in die Seite eingebettet und wird beim Öffnen nicht automatisch aktualisiert. Laden Sie eine neue HTML-Datei aus dem Repository herunter oder öffnen Sie eine neuere catalog.json. GitHub Actions erstellt die HTML-Datei nach der Katalogaktualisierung neu.

Einige vorhandene Provider prüfen eine fest hinterlegte Seite eines bereits bekannten Releases. Ein erneuter Abruf beweist nicht, dass es keine neueren Korrekturen gibt. Die ergänzenden Hinweise dieser Ausgabe wurden am 06.09.2026 geprüft und behalten ihr eigenes Prüfdatum.
